# 증시 법칙 달력 (market_calendar)

격언·계절성("11월에 사라", "짝수해 9월 조심", "12월 코스닥은 큰손이 판다")을 **날짜 위에
올린 페이지**. 대시보드 `📈 투자 > 📊 시장.모니터링 > 📅 증시.법칙달력`.

**통계는 평균이지 예언이 아니다** — 방향과 반복 여부만 보고 크기는 믿지 않는다는 게 전제.
격언 하나하나의 근거·출처·신뢰도는 [`ADAGES.md`](ADAGES.md)(1차 수집본)에.

## 구조

| 파일 | 역할 |
|---|---|
| `rules.yml` | 격언 정본. `kind`(month/cycle/window/pin/signal) + 날짜 규칙 + 통계·신뢰도(conf 1~3) |
| `dates.yml` | 규칙으로 못 뽑는 날짜 — 명절(음력)·선거·MSCI, KRX 휴장일. 미확인은 `tentative: true` |
| `build_calendar.py` | 3년치 이벤트 계산 → `static/market_calendar_report.html` (데이터를 페이지에 박음) |
| `tests/test_rules.py` | 거래일 셈·T+2·둘째 목요일·4년 주기 검산 |

FOMC 날짜는 `macro_desk/fixed_dates.json` 을 그대로 읽는다 — 두 곳에 적지 않는다.

## 크론이 없는 이유

격언은 매일 안 바뀐다. **'오늘'은 화면 JS 가 KST 로 정하고**, 이벤트는 3년치를 미리 박아
두므로 페이지는 규칙·날짜가 바뀔 때만 다시 구우면 된다(`python build_calendar.py` → 커밋 →
`deploy-pages` 의 push 트리거). 연 1회 `dates.yml` 에 다음 해 명절·휴장·선거·MSCI 만 채운다.

## 화면

1. **지금 어디쯤인가** — 이번 달에 걸린 월별 격언 + 올해 주기, 지금 지나는 구간, 앞으로 45일.
2. **1년 띠** — 코스피 / 미국 월별 평균(매년 같음) + **올해의 4년 주기 위치**(그 해만 켜짐).
   연도 버튼으로 2027(대선 전 해)·2028(대선해)을 미리 본다. 칸을 누르면 그 달 달력으로.
3. **달력** — 구간은 칸 위 색 띠(빨강 강세·파랑 약세·회색 표시만), 날짜 이벤트는 칩.
   칩을 누르면 아래 격언 카드가 열린다. 휴장은 회색 칸.
4. **격언과 근거** — 카드. ★ 신뢰도, 한 줄 격언, 통계, 단서.

## 날짜 원칙 (macro_desk 와 같다)

- 규칙으로 뽑는 것(둘째 목요일·셋째 금요일·T+2 마감·배당락)은 코드가, 기관 공표·음력·선거는 `dates.yml` 이.
- 출처가 한 곳뿐이거나 미공표면 `tentative` → 화면에 `~`. **추측한 날짜는 적지 않는다.**
- 거래일 창은 `dates.yml` 의 KRX 휴장일로 센다. 빠진 휴일이 있으면 창이 하루 어긋나므로
  창 끝은 `≈` — 통계 자체가 ±1일을 가를 만큼 정밀하지 않다.
- 4년 주기 위치는 `(year-2024) % 4` → 0 대선해 · 1 다음 해 · 2 중간선거해 · 3 대선 전 해.
  **짝수해 = 미국 선거해**가 "짝수해 조심"의 정체다.

## 규칙 추가하는 법

`rules.yml` 에 한 항목. 예 — 매년 특정 달 음영:
```yaml
- {id: kr_nov, kind: month, market: KR, months: [11], tone: strong, conf: 3,
   name: 코스피는 11월이 가장 좋다, saying: "…", stat: "…"}
```
명절·선거 기준 창은 `anchor: holiday:<id>` / `election:<id>` + `before_td`/`after_td`.
`tone` 에 `weak_then_strong` 을 주면 앞 창 약세·뒤 창 강세로 갈린다.

## 아직 안 한 것

- 배당락·연말 윈도드레싱·외국인 북클로징 — 통설은 강한데 **통계를 못 찾아** ★ 또는 미수록.
  KRX 일별 지수로 직접 계산하면 넣을 수 있다.
- 2028 명절(설·추석)·2027 이후 MSCI 일정은 미확인(`tentative`).
- 텔레그램 "이번 주 달력" 알림(원하면 매크로 데스크 텔레에 한 줄로 얹는 게 자연스럽다).
