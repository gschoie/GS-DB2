# 매크로 데스크 (macro_desk)

금리·채권·환율·원자재 숫자와 월·분기 지표 발표 일정을 한 장에 모으고, **숫자 옆에
"얼마면 무슨 뜻인가"를 같이 둔다.** 매크로를 처음 보는 사람이 혼자 읽을 수 있게 하는 게 목적.

매일 **저녁 9시(KST)** 갱신 → 대시보드 `📈 투자 > 📊 매크로.데스크`.

## 화면 구성

| 섹션 | 내용 |
|---|---|
| 📈 지금 숫자 | 미국 금리 4종·달러/환율 4종·원자재와 VIX. 1D/1W/1M/3M/12M 변화 |
| 🗓 발표 일정 | **다가오는 발표(3주) 표** — 직전 발표값·컨센서스·최근 3회 추이 + 이번 달·다음 달 달력 |
| 🧭 지표 해석 | 지표별 밴드("근원 CPI 3.5% 이상이면 …") + 시장 반응 + 한국 함의 + 원문 링크 |
| 📚 기초 | 금리·채권가격, 장단기 역전, 실질금리, '예상 대비', 미국→한국 전달 경로 |

표기 규칙: **금리는 %p(절대차), 나머지는 %(비율)** 로 변화를 적는다 — 둘을 섞으면
"10년물이 6% 올랐다"처럼 읽는 사람이 오해한다.

네 섹션 모두 제목을 눌러 접을 수 있고, **접은 상태는 `localStorage` 에 남는다** —
페이지는 매일 새로 구워지고 iframe 이 다시 로드되므로 기억하지 않으면 접어도 다음에 또
펼쳐진다. 저장이 막힌 환경(사생활 모드·사이트 데이터 차단)에서는 accessor 가 던지므로
읽기·쓰기를 전부 try 로 감쌌다 — 기억만 안 되고 화면은 그대로 돈다.

> `summary::before` 의 삼각형은 **CSS 이스케이프(`\25BE`) 대신 글자(▾)** 로 넣는다.
> 스타일이 f-string 안에 있어서 파이썬이 `\25` 를 8진 이스케이프로 먹고 화면에
> "BE" 두 글자가 찍혔다(실측). `td.r`·이중축 눈금과 같은 부류의 함정이다.

### 폐기된 계열은 에러를 주지 않는다 — 날짜로 가린다

**한국 CPI 는 FRED 에 살아 있는 계열이 없다.** OECD MEI 폐기로 전부 멈췄다(러너 실측
2026-10-11): `KORCPIALLMINMEI`·`CPALTT01KRM659N`·`KORCPALTT01IXNBM` 은 2023-11 에,
`CPALTT01KRM657N` 은 2024-03 에 마지막 관측. 그런데 **FRED 는 에러 없이 그 옛 값을
계속 내준다** — 화면에 "직전 발표: 2023년 11월 전년 +3.3%" 가 멀쩡히 찍혔다.
3년 전 숫자를 어제 것처럼 보여주는 건 빈칸보다 훨씬 나쁘다.

→ `is_stale()` 이 마지막 관측 날짜로만 가린다(월 130일·분기 230일·일 35일 초과면 버림).
발표 지연은 살린다 — 10월에 8월분 CPI가 최신인 건 정상이다. 보조 계열(`also`)도 같이 본다.
**생존 판정 기준을 두 군데 박아두지 말 것** — 프로브가 `releases.STALE_DAYS` 를 그대로
읽는다(따로 130일을 박아놨다가 분기 계열인 한국 GDP를 죽었다고 적어 오판을 부를 뻔했다).

러너 실측으로 확인된 **살아 있는** 한국 계열: 실업률 `LRHUTTTTKRM156S`(2026-07) ·

**장기국채 금리 `IRLTLT01KRM156N`(4.29%)**. 뒤 두 개는 아직 화면에 안 넣었다 —

## 발표 일정 — 규칙과 확정일을 나눈 이유

`calendar_rules.py` 가 `config.yml` 의 규칙을 날짜로 바꾼다.

- `nth_weekday: [1, fri]` 첫째 금요일 (고용보고서) · `[-1, fri]` 마지막 금요일 (PCE)
- `nth_bizday: 1` 첫 영업일 (ISM 제조업) — **공휴일은 모르고 주말만 제외**한다
- `day: 1` / `around: 12` 매월 n일 (수출입 / CPI)
- `fixed: true` **규칙이 없는 것** — FOMC·금통위

규칙으로 뽑은 날짜는 화면에 **`~`** 를 붙여 추정일임을 표시한다.

**확정일을 알면 규칙보다 확정일이 먼저다** — 규칙은 근사라 며칠씩 어긋난다
(2026년 9월 CPI: 규칙 `around 12` → 10/12, BLS 일정표의 실제 발표일 → **10/14**).
`fixed_dates.json` 에 날짜가 있으면 그 날짜를 쓰고 `~` 를 떼고, 없는 달은 규칙으로
돌아간다. `fixed: true` 인 항목(FOMC·금통위)은 날짜를 모르면 **아예 안 보여준다** —
기관 공표일을 추측해서 달력에 박으면 틀린 날짜가 사실처럼 보이기 때문이다.

```json
// fixed_dates.json — dates 는 확정일, tentative 는 출처 한 곳뿐이라 ~ 가 붙는다
{"dates":     {"fomc": ["2026-10-28"], "us_cpi": ["2026-10-14"]},
 "tentative": {"bok":  ["2026-10-22"]}}
```

`tests/test_calendar.py` 19개가 날짜 산수를 검산한다. 월말이 주말일 때 다음 달로
넘어가 그 달 달력에서 사라지던 버그를 이 테스트가 잡았다(2026-02-28 토요일).
`tests/test_releases.py` 는 직전치 변환(전월비·전년동월비·증감·분기 라벨)을 검산한다 —
**변화율을 못 구할 때 지수 원값을 대신 찍어 '코어 337.8' 이 되던 버그**를 여기서 잡았다.

## 툴팁에만 정보를 두지 않는다

처음 판은 달력 칩에 지표 이름만 찍고 설명을 `title` 툴팁에 뒀다. `cursor:help` 때문에
**커서만 물음표로 바뀌고 화면에는 숫자가 하나도 없었다** — 툴팁은 모바일에서 아예
안 뜬다. 지금은 칩이 두 줄(이름 + 컨센/직전치)이고, 누르면 그 지표의 해석 카드로
내려간다. 시세표의 ⓘ 주의문도 각주로 표 밑에 쓴다.

국기 이모지(🇺🇸·🇰🇷)도 **윈도우에서 안 그려져 `us`·`KR` 글자로 떨어진다** →
처음부터 글자 배지(`<i class="cc">US</i>`)를 쓴다.

## 텔레그램 — 저녁 9시 한 통

매크로_공부 방(`CONGPT_TELEGRAM_*`)으로 **오늘 숫자 + 앞으로 1주 발표 + 지금 구간 +
한 줄**을 보낸다(`notify.py`). `MACRO_TELEGRAM_BOT_TOKEN/CHAT_ID` 를 넣으면 그쪽이
먼저고, 둘 다 없으면 발송만 조용히 생략된다(수집·빌드는 그대로).

- **숫자는 "직전 미국 장 종가"다.** 21:00 KST는 미 장 시작(서머타임 22:30) 전이라
  그날 미국 움직임이 아직 없다. 헤더에 그대로 적는다 — 안 적으면 거짓 라벨이다.
- **평일(월~금)만 보낸다.** 토·일 21:00의 숫자는 금요일 종가 그대로여서 같은 메시지가
  두 번 더 간다. 월 21:00 = 금 종가, 화 = 월 종가 … 로 **월~금이 미국 5개 세션을
  정확히 한 번씩** 덮는다. 주말 스킵은 `notify.py` 안에 있다(`--force` 로 우회).
- **FRED 키가 있으면 야후 `us2y`(실은 5년물)는 메시지에서 뺀다.** 진짜 2년물과 나란히
  서면 숫자 둘이 어긋나 보이는데, 화면처럼 각주를 달 데가 없다.
- 본문은 **평문**이다. 서식이 필요한 데가 없고 텔레그램이 맨 URL을 알아서 링크로 만든다
  — HTML parse_mode 를 쓰면 400 → 평문 재시도 분기를 달아야 한다.
- **정시 실행에만 보낸다** — 워크플로 스텝이 `schedule` 이거나 `inputs.via == 'scheduler'`
  (GAS 시계)일 때만 돈다. 화면 `🔄 지표 갱신` 버튼은 `via` 가 없어 발송에서 빠진다
  (30번 교훈: 디스패치를 한 묶음으로 보면 수동 갱신이 텔레그램을 쏜다).

### '지금 구간'은 규칙, '한 줄'만 생성형

```
🧭 지금 구간
· 미 10년물 5.24% → 5% 이상 — 장기자금 조달이 비싸진 구간…
· 10−2년 스프레드 +0.44%p → 정상 — 장기금리가 단기보다 높다

💬 한 줄
금리는 높은 구간인데 변동성은 평온해, 둘이 엇갈려 있습니다.
```

구간 판정은 `guide.yml` 의 **`quote_reads`** 밴드로 뽑는다 — 위에서부터 **처음 맞는 것
하나**(`ge` 이상 · `lt` 미만 · 조건 없으면 폴백)라 **순서가 곧 규칙**이고, 기준을 바꾸려면
코드가 아니라 그 절만 고치면 된다. 값을 모르면 **아무 밴드도 고르지 않는다** — 폴백으로
흘려보내면 '3% 미만' 이 사실처럼 나간다(30번 교훈의 같은 부류).

그 아래 한 줄만 Gemini(`gemini-flash-lite-latest` → `gemini-flash-latest`)가 **그 판정들만
근거로** 종합한다. 숫자를 다시 나열하지 말고 엇갈리는 신호를 집으라고 지시한다.
**실패하면 한 줄만 빠지고 나머지는 그대로 간다** — 키가 없을 때도 같다.

스프레드는 `unit: pp` 로 두어 `+0.44%p` 로 적는다. `0.44%` 로 적으면 수익률처럼 읽힌다.

## 해석 가이드는 코드가 아니라 `guide.yml`

숫자는 매일 바뀌어도 해석 틀은 잘 안 바뀐다. 그래서 수집과 분리했다 — 문구를 고칠
일이 생기면 `guide.yml` 만 고치면 화면이 따라 바뀐다.

유튜브는 **영상 ID 대신 검색 링크**를 건다. 특정 영상을 박으면 몇 달 뒤 내려가 죽은
링크가 되지만 검색은 남는다. 기관 링크(BLS·BEA·연준·통계청·한은)만 직접 건다.

## 실행

```bash
pip install -r requirements.txt
python collect.py              # 수집 → static/macro_desk/<날짜>.json (120일 보관)
python collect.py --dry-run    # 저장 없이 출력만
python build_report.py         # → static/macro_desk_report.html
python notify.py --dry-run     # 텔레그램 본문만 출력(발송 안 함)
python notify.py --dry-run --force   # 주말에도 본문 확인
python tests/test_calendar.py   # 발표일 계산
python tests/test_releases.py   # 직전치 변환
python tests/test_notify.py     # 텔레그램 본문 조립·밴드 선택
```

`tests/probe_release_sources.py` 는 **러너 전용** 탐색 스크립트다(컨테이너에서는
전부 egress 차단). 소스가 죽었는지 확인할 때 일회성 워크플로로 돌린다.

매크로 데스크 작업은 **이 모듈 전용 클라우드 세션**으로 분리했다. 다른 모듈 작업과
섞이면 맥락이 길어져서다. 새 세션은 이 README + CLAUDE.md 33·34번만 읽으면 따라온다.

지금까지 선 결정 요약 — **다시 뒤집지 말 것**
- 직전치는 **BLS 공개 API(키 불필요)** + FRED 키 경로. `fred.stlouisfed.org`(그래프·CSV)는
  러너에서 막혀 있고 `api.stlouisfed.org`는 열려 있다(실측). FRED 키는 이미 등록돼 있다.
- **폐기된 계열은 에러를 안 준다** → `is_stale()` 로 날짜로만 가린다. 한국 CPI는 이래서 빈칸.
- **확정일이 규칙을 앞선다**(`fixed_dates.json`). 출처 한 곳뿐인 날짜는 `tentative`.
- **못 구한 값은 '–'** — 지수 원값·옛 값으로 메우지 않는다.
- 숫자를 **툴팁에만 두지 않는다**. 국기 이모지는 윈도우에서 깨져 글자 배지를 쓴다.
- 텔레그램은 **매크로_공부 방 · 평일 21:00 한 통**. 구간 판정은 `quote_reads` 밴드(규칙),
  한 줄만 Gemini. 헤더에 **"직전 미국 장 종가"** 를 적는다.

## 아직 안 한 것

- **확정 발표일 자동 수집** — 지금은 손으로 적는다. BLS(`bls.gov/schedule`)·연준·한은
  일정 페이지를 긁어 `fixed_dates.json` 을 갱신하면 손이 빠진다(러너 도달성 미확인)
- **금통위 확정일** — 현재 `tentative`(출처 한 곳). 한은 공식 일정으로 확인 필요
- **컨센서스 채우기** — 수동/세션 웹서치. 자동화하려면 유료 소스가 필요하다
- **한국 국고채 금리** — ECOS 키 없이도 FRED `IRLTLT01KRM156N`(장기)·`IR3TIB01KRM156N`
  (3개월)으로 된다(실측 확인). 단 월평균이라 변화 라벨을 따로 줘야 한다
- **한국 CPI 직전치** — FRED 경로 전멸. ECOS/KOSIS 키가 필요하다
- 신용스프레드, 중국 지표
