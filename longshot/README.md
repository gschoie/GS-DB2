# longshot — 자동 스크롤 캡처 도구

복사가 안 되는 앱(다올FI Pro 뉴스창 등)의 긴 내용을,
**마우스 휠을 자동으로 굴리면서 반복 캡처 → 겹치는 부분을 자동 감지해
한 장의 긴 PNG로 이어붙이는** Windows용 도구입니다.
`--ocr` 옵션을 켜면 완성된 이미지에서 **텍스트(.txt)까지 추출**합니다.

## 빠른 시작

1. 이 폴더(`longshot/`)를 Windows PC에 복사
2. `run.bat` 더블클릭 (첫 실행 시 자동으로 패키지 설치)
3. 화면이 어두워지면 **캡처할 영역을 드래그** (뉴스 본문 영역만, 스크롤바·헤더 제외)
4. 3초 카운트다운 후 자동으로 스크롤+캡처 시작
5. 맨 아래에 도달하면 자동 종료 → 바탕화면에 `longshot_날짜시간.png` + `.txt` 저장

중간에 멈추고 싶으면 **마우스를 화면 왼쪽 위 모서리로** 던지면 즉시 중단됩니다.

## 명령줄 사용

```
python longshot.py                       # 영역 드래그 선택, 이미지만 저장
python longshot.py --ocr                 # + 텍스트 추출
python longshot.py --region 1920 200 800 900   # 지난번 영역으로 바로 시작
python longshot.py --scroll 2 --delay 1.0      # 천천히·촘촘하게 (이음새가 어긋날 때)
python longshot.py --fixed-top 40              # 영역 안 상단 40px이 고정 헤더일 때
```

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `--scroll` | 3 | 한 번에 굴릴 휠 클릭 수. 이음새가 어긋나면 줄이세요 |
| `--delay` | 0.6 | 스크롤 후 대기(초). 앱 반응이 느리면 늘리세요 |
| `--fixed-top` | 0 | 영역 상단의 고정 헤더 높이(px) |
| `--strip` | 80 | 겹침 검출용 비교 띠 높이(px) |
| `--max-frames` | 200 | 최대 캡처 횟수 |
| `--out` | 바탕화면 | 저장 경로 |

## 잘 찍는 요령

- **영역은 스크롤되는 본문만** 잡으세요. 스크롤바, 고정 제목줄, 창 테두리가 들어가면 이어붙이기가 어긋납니다. 고정줄이 어쩔 수 없이 포함되면 `--fixed-top`으로 잘라내세요.
- 캡처 중에는 대상 창 위에 다른 창을 올리거나 마우스를 움직이지 마세요. 커서가 영역 중앙에 있어야 휠 이벤트가 해당 창으로 갑니다.
- "화면 변화 없음"이 3번 연속 감지되면 맨 아래로 판단하고 자동 종료합니다.

## OCR 안내

- 기본은 **Windows 내장 OCR**(`winocr`)을 사용합니다 — 별도 프로그램 설치 없이 동작하지만, Windows 설정 → 시간 및 언어 → 언어에 **한국어 언어팩**이 있어야 합니다(한국어 Windows면 기본 포함).
- 내장 OCR을 못 쓰는 환경이면 [Tesseract](https://github.com/UB-Mannheim/tesseract/wiki)를 설치하고 `pip install pytesseract` 하면 자동으로 대체 사용됩니다.

## 동작 원리

1. 선택 영역을 캡처 (mss)
2. 커서를 영역 중앙에 두고 휠 다운 이벤트 전송 (pyautogui) — 클릭하지 않으므로 뉴스 링크가 눌릴 걱정 없음
3. 다시 캡처한 뒤, 직전 합성본의 맨 아래 띠(80px)를 새 프레임에서 템플릿 매칭(OpenCV)으로 찾아 **겹치지 않는 새 부분만** 아래에 이어붙임
4. 화면이 더 이상 변하지 않으면 종료, PNG 저장 → (옵션) OCR
