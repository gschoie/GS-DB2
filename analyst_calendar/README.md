### 업무 집계 탭 (왼쪽부터)
`⟳ 업데이트` · 요약 · 발간 실적 · 세미나 실적 · 콜 · 리퀘 · 사내지원 · NDR · 콥데이 · 커버리지 · 드랍 경고 · 발간 vs 계획 · 인뎁스 달력 · 기관별 집계 · 누락 후보 (←→ 키로 넘김)

- **요약**: 카드 6장(2026년 발간 / 2026년 세미나 / 코스피 커버리지→TO-BE / 코스닥 커버리지 / 발간 vs 계획 n명 차이 / 드랍 경고 n종목 지남·n종목 4주 안) + **DAOL 리서치본부 활동표**(연간·달 선택, 배점 행, 부문×애널리스트 × Professional(가중건수·산업·기업·Weekly·Daily·경영진·NPS·ESG) / Promotive(①세미나 가중합·국민연금·우정사업본부·기관 / ②NDR·콥데이·탐방 / ③콜+리퀘 / ④사내업무지원), 최대·중앙·평균 행, 소계·합계).
- **발간/세미나/사내지원/NDR/콥데이 실적**: 같은 골격 — 연도 칩 · 월별/분기별 · 구분 칩 · ☐ 구분별로 펼치기 → 부문(기업분석 12명 / 전략 3명) › 소그룹(팀장·지속가능·지능화·휴먼·전략) › 사람 행 × 1~12월 + 합계, 소계·합계. 이름/숫자 누르면 내역 팝업. NDR 탭은 위에 '일정표·사진 끌어다 놓기' 드롭존 + 아래 'NDR 참석 기관별' 표.
- **커버리지**: 최종발간일자 파일 안내 · 수동 추가 폼 · 업종별 커버리지 표(코스피/코스닥, 담당·업종·TO-BE) · 애널리스트별 표 · 커버리지 종목 전체 목록(드랍 경고 배지·비고).
- **드랍 경고**: 기준일, 경고 규칙 설명(지남/4주 안/드랍 예정), 상태 칩 필터 · 애널리스트 칩 · 종목 표(담당·시장·보유·발간·최근 발간·마감·상태·비고).
- **발간 vs 계획**: 현재(ⓐ 발간 자료) vs 계획(ⓑ 관리 계획 '유지') 코스피/코스닥 수와 차이(+/−), 비고.
- **기관별 집계**: 세미나·NDR 참석 기관별 집계(런타임 로드).
- **누락 후보**: 캘린더 세미나 vs 엑셀 영업활동 줄 짝짓기 — '캘린더에만 / 엑셀에만' 월별 표.
- **업데이트**: 마지막 입력 시각 · '이번 받기에서 바뀐 내역'(추가/수정/삭제) · 업데이트된 영역 목록 · 되지 않은 영역 · 확인 필요 건수. 첫 진입에 모달로도 뜬다.

### 일정 화면
- 일정 칩: `● 09:00 [세미나] 기관 매니저` — 색점 = 애널리스트 색, `[세미나]/[기타]/[기업]/[NDR]` 분류 태그, 점선 테두리 = **확인 필요**(규칙으로 분류 못 한 일정), '확인' 라벨. 월: 칸당 4건 + 'n개 더보기'. 주: 월~금 5열, 칩 아래 담당자. 목록: 날짜 묶음 행(시각 · 색점 · 장부/확인 필요 배지 · 분류 · 제목 · 메모 · 담당).
- 사이드: `! 확인 필요 n건`(모달: 날짜·담당·제목·사유 목록, 눌러서 장부 넣기/빼기 — 잠금 해제 필요), 미니 달력(일정 있는 날 점), 애널리스트 검색, 체크 목록(이름 · 건수 · !확인수, '장부 제외' 표시), 모두/해제.
- 설정 모달: ① 구글 캘린더 연결(iCal 비공개 주소, 탐방 캘린더 별도) ② 기관명 분류 파일(xlsx) ③ 애널리스트 설정(부서·내용 앞말(섹터)·장부 제외·규칙 n).
