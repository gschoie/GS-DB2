# 시장 수급 동향 (market_flow)

KOSPI 수급(투자자별 · 프로그램)과 K200 선물 베이시스를 하루 4회 수집해
대시보드 리포트와 텔레그램 알림을 만든다. 단위: 현물·프로그램 억원,
베이시스는 지수 포인트.

## 스케줄 (평일, KST · `.github/workflows/market-flow.yml`)

| 시각 | 성격 |
| --- | --- |
| 10:00 | 장중 1차 스냅샷 (잠정) |
| 13:00 | 장중 2차 스냅샷 (잠정) |
| 15:40 | 마감 직후 잠정 + 장중 곡선 수집 |
| 16:40 | 거래소 확정치 + 장중 곡선 갱신 |

정시성은 GAS 시계(`gas/dispatch_proxy.gs`)가 담당하고 GitHub 크론은 안전망이다
(guard 잡이 같은 슬롯의 선행 실행을 세서 중복 발송을 막는다). 휴장일은 모바일API
`localTradedAt`이 오늘이 아니면 수집·발송·커밋을 모두 생략한다.

## 데이터 소스

**네이버(Npay 증권) — 현물 수급.** 2026-09 개편으로 옛 `finance.naver.com/sise/*`
페이지가 전부 410 으로 폐기돼 신규 JSON API 로 옮겼다.

- `m.stock.naver.com/api/index/KOSPI/trend?bizdate=` — 개인·외국인·기관 순매수.
  **과거 일자 조회가 되는 유일한 경로**(매 실행 ~30영업일 백필)
- `m.stock.naver.com/front-api/stock/domestic/integration` — 당일 투자자별 +
  프로그램(차익·비차익·전체). 과거 조회는 안 된다 → 프로그램은 당일치만 쌓인다
- `m.stock.naver.com/api/index/KOSPI/basic` — 지수·등락률·휴장 판정

**한국투자 OpenAPI — 선물 가격과 종목별 가집계.** (`KIS_APP_KEY`/`KIS_APP_SECRET`,
없으면 해당 섹션만 비표시)

- 종목마스터 `fo_idx_code_mts.mst.zip` — 코스피200 **정규** 선물 근월물 단축코드.
  코드 규약(`A01`+연도끝자리+월)은 문서마다 다르고 바뀌므로 박아두지 않고 매번 읽는다
- `inquire-price` — 선물 현재가·시장베이시스·이론가·괴리율·미결제약정
- `inquire-daily-fuopchartprice` + `inquire-daily-indexchartprice` — 일별 베이시스 소급
- `foreign-institution-total` — 외국인·기관 순매수/순매도 상위 종목(장중 가집계)

  274개 중 선물은 해외뿐). KRX 는 프로그램 접근을 막고, 한투 OpenAPI 에는 선물
  투자자별 엔드포인트가 없다. → **베이시스로 대체**(아래)
- **기관 세부 7항목**(연기금·투신·보험 등) — 신규 API 의 투자자 구분은 3개뿐.

## 리포트 구성 — 🔀 현·선물 괴리 (베이시스)

"외국인이 선물을 샀나"는 이제 알 수 없다. 대신 **선물이 현물보다 비싼가 싼가**로
같은 질문에 답한다 — 그것이 차익 프로그램이 어느 쪽으로 걸리는지를 직접 설명한다.

- **칩 줄** — 선물 종가·등락률 / 현물 KOSPI200 / 시장 베이시스(콘탱고·백워데이션
  배지) / 괴리율과 이론가 / 미결제약정과 잔존일
- **차익 프로그램 vs 베이시스 20일 이중축 차트** — 차익 순매수(바·좌축 억원)와
  시장 베이시스(라인·우축 포인트)를 0선 공유로 겹쳐 그림
- 시그널 룰: 백워데이션+차익매도 / 콘탱고+차익매수 / 괴리율 |0.5%| 이상

**월물 경계 주의** — 베이시스는 만기까지 남은 기간에 비례해 커진다. 그래서 일별
소급은 날짜마다 *그날의 근월물*을 쓰고(만기 = 분기 두 번째 목요일), 그래도 교체일에는
레벨이 한 번 튄다. 화면에도 그렇게 적어둔다.

## 2차 확장 아이디어
